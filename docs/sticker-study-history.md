## 可复现参数

- 输入缩放到 320px 宽，对应网页中的 80px 输入画布宽；四周各加 40px 透明空间。产物显示宽 100px，因此不同边宽不会压缩图案。
- MMSys 使用 `public/files/logos/MMSys 26 Logo.png`，保留 alpha，RGB 重着色为 90。
- 水獭使用 `public/files/stamp-preview/vr-otter.png`（Figma 55:2）；字标使用 `public/files/stamp-preview/vr-logo-transparent.png`（Figma 102:68）。均为无额外贴纸底层的透明导出，3/4/5px 从原始 alpha 生成，不是追加旧纸边。
- alpha 50% 阈值 → Close Disk:8 → Dilate Disk:12/16/20 → Close Disk:8 → Open Disk:4 → 放大至 8× 网页尺寸 → Blur 0x6 → 50% 阈值 → Triangle 缩回 4× → 白底 → 原图叠加 → lossless WebP。最终缩采样后不再二值化。
- 闭运算用于收拢小缝隙，不保证填满任意大小的内部孔洞。平滑后的厚度为近似值。
- 阴影由 CSS 添加；2× 检视模式同时放大图像、白边和阴影。阅读场景保持实际尺寸。

## 旧流程审阅

`scripts/optimize-images.mjs` 仅压缩现有已烘焙素材，不执行纸边算法。`docs/sticker-logo-recipe.md` 描述另一套 ImageMagick 膨胀、双遍模糊阈值与外环描边流程，其源图像素常量不能直接解释为最终 CSS 厚度。

`utils/sticker_effect.html` 的问题：

1. 最终合成没有使用平滑后的 borderCanvas，双遍平滑结果被丢弃。
2. smoothBorderCanvas 第二遍的输入和临时目标相同，clearRect 会清除将要采样的内容；由于结果未被采用，该问题目前被遮蔽。
3. ensureSrcCache 仅按宽高提前返回，同尺寸换图即使把 cachedSrcData 设为 null，也无法保证缓存刷新。
4. renderPending 时直接返回，新参数没有排队，拖动期间可能丢失最后一次调整。
5. 下载数据固定为 PNG，但扩展名沿用上传文件类型，可能出现 MIME 与扩展名不一致。

本次没有修改旧工具；预览用独立、确定性的离线生成脚本绕开以上路径。旧成品仍作为基线，MMSys 的颜色和轮廓也发生变化，因此它不是仅改变边宽的严格单变量实验。

## 4px 卡纸压凸试验

`#relief-study` 增加平面、轻压凸（card）、较强压凸（raised）三档。`preview:stickers` 在原始图案与 4px 白底生成后，派生卡纸版本，不改变 alpha 或画布尺寸。原图最后合成，保留其不透明像素；抗锯齿半透明边缘与新的纸色正常混合。

纸边基础色 RGB 248/248/246；白底 alpha 经过 2.4 个源像素模糊，沿左上到右下采样局部坡度，轻档/强档的明暗幅度分别为 30/55。图案 alpha 经 2px 模糊后，以相反方向的小幅明暗模拟纸面压印。输入为 4×，所有明暗已离线烘焙；网页只显示同一组轻接触阴影，可关闭以隔离观察纸边浮雕。

验证：三素材 × 两个新档位，与平面版逐像素对比 alpha 均无差异；RGB 确有变化。构建和资源检查通过。视觉对比支持实际尺寸及 2× 检视。

## 修正：浮雕作用于图案本身

根据用户提供的同色卡纸压花参考，上一版纸边倒角方案停止使用。当前对比为平面印刷、同色盲压凸（blind）、保留印色压凸（ink）。新高度图取原图 alpha × 墨色覆盖（亮度反相），保留字形孔洞与插画内部线条；4px 纸边不作为高度输入。白色插画区域视为低区，不删除透明度。

高度图经过 2.2 个源像素的柔化，显式转为单通道，并检查 buffer 长度，避免 RGB 通道被误读为空间采样。光源来自左上，坡度控制图案明暗；盲压凸统一为 RGB 244/244/240，保色版以原像素颜色叠加较轻的起伏。仍是二维模拟，复杂彩色图案的高度来自墨色推断，不代表真实雕刻结构。

## 外轮廓平滑

对膨胀后的白底再做闭运算与开运算，合并细小凹口、去掉尖细凸起。轮廓在 4× 工作尺寸上整理，然后放大到 8× 平滑，最后使用无振铃的 Triangle 滤波缩回 4×，恢复半透明抗锯齿。保留宏观形状和目标 4px 白边，允许局部轮廓略有变化。纸边调整与图案浮雕高度图分开。灰度蒙版读取为原始缓冲区前显式转为 sRGB RGBA，防止灰度+alpha 两通道被误按四通道处理。

## 柔和压花与淡彩 / 2026-09-07

根据花卉压花请柬与浅色压印参考，图案高度采用 1.4px / 5px 两级模糊，以 65% / 35% 合成（均为 4× 生成像素），兼顾细线和圆缓肩部。法线漫反射代替单向亮暗叠加，并加入浅凹槽与右下短接触暗部，不添加镜面高光、纸纹噪点或滤镜。外轮廓算法不变。

新增 pastel 试样：暖白 RGB 247/246/241 与 32% 油墨浓度；预览右列默认淡彩，可切回 ink 原色强度。blind、ink、pastel 共用同一高度与纸底 alpha，三素材逐像素核对 alpha 完全一致。高度仍由墨色推断，无法从二维图恢复花瓣式真实体积。npm run check 通过。

## 原色浮雕独立对比

按用户“仅参考形态”的要求，原色浮雕作为独立试样与平面、盲压凸、淡彩同时展示，取消颜色切换。原色版直接使用合成图 RGB 作为底色，移除此前暖纸底色带来的通道偏移，仅添加现有浮雕明暗。MMSys 继续沿用该轮试样的中性灰重着色，并在预览中注明。桌面使用两列，移动端单列；4px 轮廓和高度算法不变。
