# 可缩放排版验证记录

日期：2026-11-14。基线为 `ded0efc`，实施分支为 `codex/scalable-typography`。

## 方法

- 使用独立的基线源码快照，避免将其他 worktree 的预览产物当作基线。
- Playwright 工具及浏览器安装在项目外；项目运行依赖未增加。截图和测量记录位于本次环境的 `/tmp/opencode/typography-*`，属于临时验收产物。
- 截图等待字体加载及布局稳定，基线比较使用相同的浏览器、视口、默认字号和减少动态效果设置。
- Firefox 通过 `font.size.variable.x-western` 实际设置默认字号，而非注入 CSS 模拟默认字号。
- Chromium 通过本地测试扩展调用 `chrome.tabs.setZoom()` 设置真实标签页缩放，使用 `getZoom()`、`innerWidth` 和 `devicePixelRatio` 交叉验证。
- 根字号覆写为 32px 仅用于额外的动态文字缩放压力测试，不作为操作系统文字缩放实测。
- 布局自动检查包含页面横向溢出、脚本异常、图片成功加载；交互检查包含 Tab 焦点是否完全被页头遮挡。远程视频播放器与统计脚本在浏览器测试中拦截，视频播放本身不在本次验收范围。

## 结果

- `npm run check` 通过：主题、论文预览、会议注释、页面转场、项目页、共享模板、生产构建与生成资源引用检查。
- 默认字号 16px：三个主基准（1280×832、820×1180、402×874）× 四个生产页面，对比姓名/标题、正文、头像、章节、项目插图和页脚等关键边界；最终生产产物相对基线的最大几何差为 0.015625 CSS px（亚像素取整）。截图按通道差值大于 16 的阈值比较，差异比例均小于 0.001%。
- 补充视口：1440、1024、900、899、640、390、320 CSS px，四个生产页面通过布局检查。
- Firefox 默认字号 20/24/32px：四个生产页面在补充视口中完成检查；正文随字号成比例增长。32px 叠加行高 1.5、字距 0.12em、词距 0.16em、段距 2em 的最终生产产物检查通过。
- Chromium 实际页面缩放 100/125/150/200/400%：四个生产页面通过横向溢出检查，1280px 浏览器窗口在 400% 时布局视口为 320 CSS px。
- Chromium 动态根字号 32px 叠加文字间距压力测试：四个生产页面通过检查。
- Chromium 默认字号与 Firefox 32px：1280、402、320px 下分别检查正常/减少动态效果，共 12 组交互检查。主题切换、随系统配色变化的 favicon、新闻操作、项目页往返和键盘焦点检查通过。
- 保留的 `publications.html` 与 `cv.html`：三个主基准下，Firefox 32px 叠加文字间距检查通过。

## 验证边界

- Safari/WebKit 未实测：本机缺少 WebKit 运行所需的系统库。iOS/Android 真机与系统文字缩放设置未实测。
- `text-scale` 为渐进增强；不支持的浏览器仍依靠标准默认字号和页面缩放。
- 本记录不是全面无障碍认证。再次调整字体、内容或断点后，应按 `responsive-baselines.md` 重验相关组合。
