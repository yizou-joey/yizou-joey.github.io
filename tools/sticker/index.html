4px 是什么？

指最终显示尺寸下的目标外扩宽度。原图画布按指定宽度缩放，不裁切透明留空；成品画布额外保留左右各 10px。4× 导出时，80px 图案画布对应 320px，成品宽度为 400px。

哪些效果在图片里？

白色底形、图案配色和浮雕明暗已烘焙。页面上的接触阴影与检视背景不会导出。高度由图案的墨色与透明度推断，无法恢复真实三维体积。

为网页准备

PNG 是无损基准；WebP 使用高质量编码。搭配参数 JSON 可以从原图重新生成。成品的显示宽度应按画布计算，勿将整张图片压缩到图案宽度。

设计从哪里来？

4px 白边与图案压花来自多轮试验。邮票排版、旧方案、素材来源与已停止采用的试样的结论见研究说明，完整图片档案仅在本地保存。
