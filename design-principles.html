Guide

Design Principles In Practice

Content First

Let meaning, not decoration, set priority.

Clear Hierarchy

Use typography, alignment, and whitespace to guide reading.

Meaningful Color

Reserve emphasis for roles such as venues and awards.

Clear Feedback

Communicate actions and state changes clearly, with visible focus and motion that supports understanding.

Flexible Layout

Allow wrapping, growth, and reflow while supporting zoom and reduced motion.

Shared Rules

Reuse shared primitives and make exceptions only for distinct responsibilities.

Implementation Contract

CSS is the implementation source of truth; keep this visual reference and its companion guide aligned.
