Guide

Design Principles In Practice

Content First

Let meaning, not decoration, set priority.

Clear Hierarchy

Use typography, alignment, and whitespace to guide reading.

Meaningful Color

Reserve emphasis for roles such as venues and awards.

Clear Feedback

Communicate state changes clearly, keep keyboard focus visible, and respect reduced-motion preferences.

Flexible Layout

Let content wrap and reflow without clipping as space narrows or text grows. The homepage moves the portrait and contacts from beside the biography to above it. Adapt layout to space, and support touch, mouse, and keyboard at every width.

Shared Rules

Reuse shared primitives and make exceptions only for distinct responsibilities.

Implementation Contract

CSS is the implementation source of truth; keep this visual reference and its companion guide aligned.
