Design Guide

Design Language.

A quiet personal academic archive: warm paper, editorial typography, and clear hierarchy.

Visual Direction

Content comes before decoration. Research and personal expression lead; the interface stays out of the way.

Content First

Let meaning, not decoration, set priority. Establish reading order with type, alignment, whitespace, and fine dividers.

Shared Rules

Reuse visual and interaction rules for the same meaning; make an exception only for a distinct responsibility.

Meaningful Colour

Reserve accents for roles such as venues and awards. Communicate state with visible focus and motion that supports understanding.

One System, Many Widths

Content reflows without clipping. Layout adapts to available width rather than device names.

Implementation Contract

CSS is the implementation source of truth. This guide and its companion document describe the same values and states.
