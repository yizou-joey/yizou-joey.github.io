Service Annotation

The homepage service list uses a coordinated underline and tooltip connector instead of the ordinary native underline.

At ≥64em with a fine hover pointer, hover or keyboard focus opens the floating annotation; keyboard focus is immediate. Escape, scroll, or resize dismisses it. On touch or narrow layouts the annotation is visually hidden and the link remains navigable. Its text is referenced by aria-describedby.

Theme Control

Try the single button in the header. It keeps one fixed slot and names the destination theme; these marks are a non-interactive diagram.

Hover changes ink only, with no fill. A fine-pointer press scales to 0.97 (160ms in / 100ms out). Supported pointer transitions crossfade the whole page without a wipe; unsupported path interpolation uses icon fade/scale. Keyboard, reduced motion, initial paint, storage updates and unsupported transitions are immediate. A repeated click interrupts motion and applies the latest choice; the slot does not move or duplicate content.
